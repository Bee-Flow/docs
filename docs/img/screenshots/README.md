# Screenshots

Drop product screenshots here. PNG, max 1600px wide, 8-bit colour, no shadow/frame (the docs theme adds one).

Filename convention: `<section>-<short-name>.png`, e.g.:

- `01-appstore.png`, `02-topbar.png`
- `wizard-01-sync.png`, `wizard-02-integrations.png`, `wizard-03-privacy.png`, `wizard-04-license.png`
- `chat-toolcall.png`
- `kb-citations.png`
- `automation-builder.png`
- `dlp-policy.png`
- `voice-call.png`
- `license-apply.png`

Pages reference these by relative path. Until the real screenshots land, MkDocs will render a broken-image icon — that's fine; it doesn't fail the build.
