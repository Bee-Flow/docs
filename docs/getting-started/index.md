# Getting started

There are two ways to run Bee Flow:

1. **As a Nextcloud app** — install from the Nextcloud App Store. The connector runs as an ExApp container next to your Nextcloud. This is the recommended path for most teams.
2. **Self-hosted standalone** — run the Bee Flow server + frontend yourself, without Nextcloud. Useful for evaluating outside an existing Nextcloud deployment.
