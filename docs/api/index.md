# API

Bee Flow exposes a REST + Server-Sent Events API. The frontend in this repo is one client; you can build others.

Base URL: `https://beeflow.example.com/api` (self-hosted) or `https://api.beeflow.ai` (hosted).

## Pages

- [Authentication](auth.md) — how to obtain a session JWT.
- [REST reference](rest.md) — endpoints by area.
- [Streaming (SSE)](sse.md) — chat streams and tool-call events.

## OpenAPI

A draft OpenAPI 3.1 spec lives in [`server/openapi.yaml`](https://github.com/Bee-Flow/beeflow/blob/main/openapi.yaml). It's autogenerated and lags behind hand-written reference here in some places — file an issue when you spot drift.
